SFlip — 未签名测试版

安装到当前 Windows 用户的程序目录，并创建开始菜单快捷方式。

需要 Windows App Runtime 2.4 x64。本安装包不包含运行库，也不会自动下载或安装运行库。复制程序文件前，会检测当前用户是否能加载兼容版本；若不可用，将提供微软官方下载链接。请自行安装运行库，再回到此处点击“上一步”，然后点击“安装”重新检测。

升级或卸载前，请先从托盘退出 SFlip。安装器不会强制关闭或自动启动应用。安装完成后，请从开始菜单启动。

安装、重装和卸载均保留原配置。从绿色版迁移时，请先退出原副本，改用开始菜单入口；若之前开启了登录启动，请在新应用中关闭后重新开启，以更新启动路径。

卸载仅移除本安装目录中的程序和快捷方式，保留配置及共享微软运行库。仅当登录启动项指向本安装目录时才会删除该项。

安装器不会开启防火墙规则、修改显示器设置、猜测 USB 映射、授予权限或开启登录启动。
