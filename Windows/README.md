# SFlip Windows 使用说明

SFlip 常驻 Windows 托盘，可调节显示器亮度、对比度和音量，按 USB 设备状态切换显示器输入源，也可与另一台电脑协同切换。

## 安装与升级

支持 x64 Windows 10 1809 及以上版本和 Windows 11。安装版与绿色版都需要 **Microsoft Windows App Runtime 2.4 x64**。

### 安装版

运行 `SFlip-Setup-x64.exe`，按向导安装。默认安装到 `%LOCALAPPDATA%\Programs\SFlip`，无需管理员权限。完成后从开始菜单打开 SFlip。

安装包不包含运行库。若提示缺少依赖，先安装 [Windows App Runtime 2.4 x64](https://aka.ms/windowsappsdk/2.4/2.4.0/windowsappruntimeinstall-x64.exe)，再返回安装向导重试。

### 绿色版

解压完整绿色版压缩包到固定目录，保留 `runtime` 子目录，运行 `SFlip.exe`。不要只复制入口文件；绿色版同样需要安装上述运行库。

### 升级与卸载

升级前先从托盘退出 SFlip。安装版运行新安装器；绿色版替换完整程序目录。原配置会保留。

更换程序位置或从绿色版改用安装版后，更新快捷方式；已开启登录启动的用户，在新程序中关闭再开启一次登录启动。

安装版可从 Windows“设置 → 应用”卸载。卸载保留 `%LOCALAPPDATA%\DisplaySwitcher` 中的配置和诊断记录。需要彻底清除时，先退出 SFlip，再删除该目录。

## 开始使用

从托盘菜单打开“设置”。各页自动保存：开关和选择器修改后立即保存，文本字段在结束编辑或按 Enter 时保存。无效输入会恢复最后有效设置并显示错误。

### 显示器调节

在“显示器”页启用需要使用的亮度、对比度或音量控制。打开对应的托盘开关后，可直接从托盘调节。新显示器的控制项默认关闭。

“读取 DDC 参数”获取当前值。开启“联动调节所有显示器”后，亮度、对比度和音量各使用一组功能开关、托盘开关和滑杆；开关不一致时显示“部分开启”，值不同时显示“混合”。关闭联动后恢复逐台控制。

显示器和连接链路需要支持 DDC/CI。部分线材、转接器、扩展坞或 KVM 可能无法传递这些控制命令。

### USB 自动切换

1. 在“USB 切换”页选择设备，或使用“学习”识别要跟随的设备。
2. 为显示器填写“USB 离开后切到的输入源”。输入源编号取决于显示器；留空表示该显示器不参与切换，至少需要配置一台。
3. 开启“USB 自动切换”。设备离开时切换输入源，重新接入时唤醒本机显示器。

USB 切换可以单独使用。“联动协同”用于在切换时唤醒选定的另一台电脑，需先完成对应协同配置。

### 双机协同

在两台电脑上分别填写协同配置：

- 配置名称；
- 对端 IP 地址或主机名；
- 对端端口，默认 `49731`；
- 两端相同的配对码；
- 切换到对端时使用的显示器输入源。

字段完整后即可开启配置，对端暂时离线也能保存。两端运行 SFlip 后会自动连接，也可点击“检测连接”。连接成功时显示“已和对端（配置名）建立连接”，之后可从托盘选择“切换到 {配置名称}”。

USB 与协同设置独立保存。关闭协同不会关闭 USB 自动切换；已有联动选择会保留，重新开启协同后恢复。删除被联动引用的协同配置会同时关闭该联动。

## 常见问题

**程序无法启动或安装器提示缺少依赖**

安装 Windows App Runtime 2.4 **x64** 后重试。绿色版还需确认入口文件旁保留完整的 `runtime` 目录。

**对端无响应**

确认对端正在运行 SFlip，地址和端口填写正确，两端配对码相同。点击“检查网络权限”；若系统询问，请允许专用网络访问。仍无响应时检查两台电脑的网络连通性与防火墙。

**显示器不能调节或切换**

确认显示器菜单中的 DDC/CI 已开启，并检查线材、扩展坞和 KVM 是否支持传递控制命令。输入源切换还需确认所填编号正确。显示器连接发生变化后可重新检测；提示需要关联时使用“重新绑定”。远程桌面会话中不执行显示器控制。

**设置保存失败**

原配置会保留，自动操作暂停。检查磁盘空间及配置目录的写入权限，修正后重新保存。需要处理配置文件时，先备份 `%LOCALAPPDATA%\DisplaySwitcher`。

**需要提交故障信息**

在“常规”页开启“详细诊断记录”，复现问题后到“诊断”页刷新并复制预览。排查结束后可关闭记录。

## 开发与测试

正式应用位于 `Windows/DisplaySwitcher.Native/`，使用 C++/WinUI 3；绿色版启动器位于 `Windows/DisplaySwitcher.Launcher/`。

开发前阅读 [项目约束](../AGENTS.md)、[通信协议](../PROTOCOL.md) 和 [Windows 开发清单](DEVELOPMENT_CHECKLIST.md)。构建需要 Visual Studio 2026 的 C++ 桌面开发及 Windows App SDK C++ 组件、Windows SDK 10.0.26100.0 和 v145 工具集。

在仓库根目录运行：

```powershell
.\Windows\build-windows.ps1
```

脚本构建应用和启动器、运行原生自动测试，并生成 `Windows\dist\SFlip.exe` 及 `runtime`。测试使用模拟网络、时间和设备。

生成安装包：

```powershell
.\Windows\build-installer.ps1
```

输出位于 `Windows\outputs\`。
