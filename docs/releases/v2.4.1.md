Windows 和 macOS 统一更新至 **2.4.1（构建 25）**。

- 更新两端应用图标及菜单栏 / 托盘图标，提高小尺寸下的辨识度。
- 修复 macOS 登录启动的状态显示、系统审批恢复和设置开关对齐。
- 统一 macOS 媒体快捷键与音量控制的功能开关和权限流程，改进取消申请、授权返回及撤权后的状态处理。
- 优化 Windows 启动响应：显示器枚举移到后台，首次设置窗口复用启动快照，减少重复扫描。

## English

Windows and macOS are updated to **2.4.1 (build 25)**.

- Refreshed application and menu bar / tray icons on both platforms for better legibility at small sizes.
- Fixed macOS login startup status, approval recovery, and switch alignment.
- Unified macOS media-key and display-volume switches with their permission flows, including cancellation, returning from authorization, and permission revocation.
- Improved Windows startup responsiveness by enumerating displays in the background and reusing the startup snapshot when opening the initial settings window.

Quit the previous version before upgrading. The configuration format and network protocol version are unchanged.

The Mac build supports Apple Silicon on macOS 12 or later and is not notarized. Download with Safari, move SFlip.app to Applications, and use **System Settings → Privacy & Security → Open Anyway** if the first launch is blocked. See the [installation guide](https://github.com/maizihk/SFlip/blob/v2.4.1/macOS/INSTALL.md).

The Windows build supports x64 Windows 10 1809 or later and requires Windows App Runtime 2.4 x64. For the portable edition, extract the complete ZIP and keep the `runtime` folder beside `SFlip.exe`.
