Windows 和 macOS 统一更新至 **2.4.0（构建 24）**。

- 新增英文界面，可在常规页选择跟随系统、简体中文或 English。
- 协同配置支持对端离线时开启，改进连接检测、自动连接和状态显示。
- 联动调节时统一功能开关、托盘选项和 DDC 参数读取，整理双端设置布局。
- 改进 Windows 显示器识别和托盘恢复。
- 新增英文 README。

Windows and macOS now share version **2.4.0 (build 24)**.
