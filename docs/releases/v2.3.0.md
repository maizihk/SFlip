## 本次更新

- 应用更名为 SFlip，原配置继续使用。
- macOS 增加 DMG 拖拽安装包。
- Windows 增加中英文安装向导，支持安装、升级和卸载，继续提供绿色版。
- 修复对端离线时错误切屏，以及连续调节显示器时使用旧数值的问题。

## 下载

| 平台 | 安装版 | 压缩包 |
| --- | --- | --- |
| macOS | [DMG](https://github.com/maizihk/SFlip/releases/download/v2.3.0/SFlip-v2.3.0-macOS-arm64.dmg) | [ZIP](https://github.com/maizihk/SFlip/releases/download/v2.3.0/SFlip-v2.3.0-macOS-arm64.zip) |
| Windows | [安装程序](https://github.com/maizihk/SFlip/releases/download/v2.3.0/SFlip-v2.3.0-Windows-x64-Setup.exe) | [绿色版](https://github.com/maizihk/SFlip/releases/download/v2.3.0/SFlip-v2.3.0-Windows-x64-portable.zip) |

- **macOS**：Apple Silicon、macOS 12 及以上。打开 DMG，将 `SFlip.app` 拖入“应用程序”。
- **Windows**：x64、Windows 10 1809 及以上，需要 [Windows App Runtime 2.4 x64](https://aka.ms/windowsappsdk/2.4/2.4.0/windowsappruntimeinstall-x64.exe)。绿色版完整解压后运行 `SFlip.exe`，保留 `runtime` 文件夹。

升级前退出旧版，原配置会保留。
